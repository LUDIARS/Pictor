# 葛葉：加筆テクスチャと C案ステージデモ

対象は Fg の制作依頼、描画実装は Pc。Astra の既存 PN パッチ直接レイマーチ実装を基準にした。

## 制作内容

- 顔：元のUV配置を参照して肌の淡い色差、唇の細部、赤い虹彩の放射模様を加筆。
- 冠：既存の装飾に細い彫り線と疎らな磨き跡を追加。形状は元モデルのPNパッチを維持。
- テクスチャ編集は組み込み imagegen。Face / Crown の生成画像は各1254×1254。元画像は各2048×2048であり、高解像度化したとは扱わない。
- 顔・髪・冠・その他を元テクスチャ名で分類し、描画側で粗さと反射を分けた。冠の金属と赤い宝石は反射設定を分ける。衣装の金装飾を個別金属マスクで分離する処理は含めない。
- 暗い背景、動く暖色キー、弱い寒色フィル、控えめな赤紫の後方光。キーは縦方向3サンプルの近似で、影レイや厳密な面光源積分ではない。
- KS の Kuzuha_turnR_ver1.fbx / jnt_Head の強い回転曲線を正規化した既存抽出結果を、18秒の小さなカメラ回り込みに使用。全身モーション再生や骨格のリターゲットではない。
- 髪・服の物理と当たり判定は変更しない。スミアはこの照明動画に混ぜず、別の依頼として維持する。

## 確認と制約

Release ビルドを行い、Pictor 本体の専用成果物フォルダから Excubitor 経由で制作用静止画・動画を書き出した。Concordia testing claim/release を利用する。単体・統合テストは実行しない。

静止画で7枚すべてのテクスチャ読込を確認。元画像と加筆版の両方を同じステージ設定で描画し、顔と冠の大きなUVずれがないことを目視した。全UV境界を数値保証したものではない。

完成MP4は ffprobe で18.000秒、432フレーム、24fps、800×960、H.264、7,939,279 bytesを確認。録画ログ432件の unresolved_previous_frame はすべて0。開始・中間・末尾フレームを目視した。エンコーダは終了コード0で終了し、制作起動の claim は解除した。Discord端末での再生プレビューは確認していない。

加筆版は採用検討用の制作素材。毛穴ノイズを強くせず元の顔立ちを保つ方向とした。法線／粗さの独立マップ、髪の異方性、角膜の追加形状、SSS、ソフトシャドウ、mip生成は今回の実装に含まない。現在は既存の単一 mip テクスチャ参照を維持している。

## 生成指示

Face：元のUV島、顔の各部位、瞳孔、ほくろと境界を保つ。控えめな肌の色差とごく弱い毛穴、頬・鼻・耳の血色、唇の細部、既存赤虹彩内の細い放射模様を追加する。若いアニメの顔立ちを保ち、髭、老化、追加のほくろやそばかす、強い影、ステージ光を焼き込まない。人物画へ描き替えずアトラスのまま出力する。

Crown：すべてのUV島の位置・大きさ・輪郭と元の装飾意匠を保つ。くすんだ金へ繊細な彫り線、疎らな磨き傷、淡い金色の変化を加える。暗赤の宝石は位置と形状を保つ。新しい紋様、強い白反射、汚れ、破損、劇的な焼き込み照明を追加せず、アトラスのまま出力する。
